# Clip Studio

Локальная студия нарезок смешных моментов. Вы пишете, что нужно («5 клипов, где он спорит с чатом»), а приложение делает остальное:

- проверяет права через юридический шлюз и белый список источников;
- распознаёт речь (faster-whisper) или берёт готовые субтитры;
- ищет моменты «редакцией из четырёх менторов» на Claude Sonnet: монтажёр, комик, аналитик удержания, редактор-юрист;
- монтирует клипы 9:16 с подсветкой слов, хуком и титром автора (ffmpeg);
- даёт разобрать готовый клип менторам на Claude Opus и применить правки одной кнопкой;
- публикует в VK Видео, YouTube и Telegram (по умолчанию приватно) и готовит пакеты для Rutube, Дзена, VK Клипов и OK.

## Быстрый старт

1. Установите Python 3.10+ и ffmpeg (подробно в [docs/GUIDE.md](docs/GUIDE.md#установка)).
2. Установите и войдите в [Claude Code](https://code.claude.com/docs/en/setup) (подписка Pro или Max), или выберите ручной режим.
3. Запустите `start.bat` (Windows) или `./start.sh` (macOS, Linux). Откроется `http://127.0.0.1:8765`.
4. Добавьте источник в «Источники и права», загрузите видео, опишите запрос в «Студии».

## Через Claude Code

В папке проекта запустите `claude` и пишите `/clip 5 клипов, где он спорит с чатом`. Другие команды: `/add-source`, `/mentor`, `/setup`.
Чтобы управлять с телефона, используйте `claude remote-control`.
