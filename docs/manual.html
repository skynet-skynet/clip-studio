Методичка Clip Studio

Как превращать длинные видео в короткие смешные клипы: найти моменты с помощью Claude, вырезать их с субтитрами и хуком, проверить и выложить в VK, YouTube и Telegram. Без нарушения чужих прав.

Версия 0.2 · октябрь 2026. Факты о площадках проверены на эту дату; правила меняются, ссылки на первоисточники — в конце.

Быстрый старт за 10 минут

  1. Скачайте программу

    Готовая сборка для Windows — архив ClipStudio-windows.zip в разделе Releases репозитория. Для macOS и Linux — запуск из исходников (раздел «Установка»).

  2. Распакуйте в «Документы» и запустите ClipStudio.exe

    Откроется окно интерфейса. Чёрное окно консоли не закрывайте — это сервер программы.

  3. Подключите Claude

    Установите Claude Code и войдите (подписка Pro или Max). Без него работает ручной режим через claude.ai.

  4. Добавьте источник

    «Источники и права»: для своих видео уже есть «Мои видео». Для чужих — только с письменным разрешением автора.

  5. Загрузите видео

    «Видео» → файл с компьютера (лучше с субтитрами .srt) или ссылка на разрешённый канал.

  6. Опишите, что искать

    «Студия» → например: 5 клипов, где он уверен в себе, а потом всё идёт не так. Нажмите «Найти моменты».

  7. Выберите и отрендерьте

    Смотрите кандидатов, жмите «Взять», затем «Отрендерить». Точная правка — кнопка «В монтаж».

  8. Разбор и публикация

    «Клипы» → «Разбор менторами» → «Применить правки» → «Опубликовать» (по умолчанию приватно).

Установка

Вариант А: готовая программа для Windows

В архиве уже есть Python, все библиотеки и ffmpeg. Ничего ставить не нужно, кроме Claude Code.

  1. Откройте репозиторий на GitHub → Releases → скачайте ClipStudio-windows.zip. Свежая сборка без релиза — во вкладке Actions → последний запуск build → артефакт ClipStudio-windows.
  2. Распакуйте в папку, куда можно писать, например Документы\ClipStudio. Не в Program Files: рядом с программой хранятся настройки и видео.
  3. Запустите ClipStudio.exe. Если Windows SmartScreen предупредит о неизвестном издателе — «Подробнее» → «Выполнить в любом случае». Программа не подписана сертификатом.

Первая транскрибация скачает модель распознавания речи (около 500 МБ для small) — нужен интернет.

Вариант Б: из исходников (Windows, macOS, Linux)

  1. Python 3.10+ (python.org, на Windows отметьте Add python.exe to PATH) и ffmpeg.
winget install Gyan.FFmpeg          # Windows
brew install python ffmpeg          # macOS
sudo apt install python3 python3-venv ffmpeg   # Ubuntu
  1. Скачайте проект (Code → Download ZIP или git clone) и запустите start.bat (Windows) или ./start.sh. Первый запуск ставит зависимости.

Claude Code

Нужен для автоматического поиска моментов и подключения Claude к программе. Требует подписку Pro, Max, Team или Enterprise (бесплатный план claude.ai не подходит).

irm https://claude.ai/install.ps1 | iex           # Windows, PowerShell
curl -fsSL https://claude.ai/install.sh | bash    # macOS, Linux

После установки один раз выполните claude в терминале и войдите через браузер.

Видеокарта

Без видеокарты модель small распознаёт час видео примерно за 15–40 минут. С NVIDIA выберите в «Настройках» модель large-v3 и устройство «Видеокарта NVIDIA» — быстрее и точнее. Самый быстрый путь — загружать видео сразу с субтитрами .srt/.vtt: распознавание не понадобится.

Права и белый список

Главное правило: режем только то, на что есть основание. Программа не скачает видео из источника, которого нет в белом списке, и запишет каждое решение в реестр прав.

cc-byКонкретное видео под Creative Commons AttributionСсылку на оригинал; автор указывается в каждом клипе

Чего программа не пропустит

Видео с чужого канала без разрешения; CC BY-ND (запрещает переработку, а нарезка с субтитрами — это переработка); разрешение одного канала для видео с другого канала.

Почему не «цитирование»

Статья 1274 ГК РФ разрешает цитировать в информационных, критических, научных и учебных целях в оправданном объёме. Канал из подряд идущих смешных фрагментов чужих видео обычно под это не подходит: в нём нет разбора или новости. Поэтому Clip Studio на цитирование не опирается.

Люди в кадре

Статья 152.1 ГК РФ охраняет изображение гражданина. Ментор-юрист снижает оценку моментам, где высмеивают случайных людей, детей, сотрудников. Сомневаетесь — не публикуйте или заблюрьте лицо.

Письмо автору

Привет! Я делаю нарезки смешных моментов (пример: ссылка). Хочу резать ваши стримы для VK Клипов и Shorts. В каждом клипе будет ваш ник и ссылка на канал. Можно ли? Есть ли темы, которые не трогать? Можно ли включать монетизацию на нарезках, или делим доход?

Ответ — скриншотом в папку proofs/, путь — в поле «Доказательство» источника. Реестр прав выгружается в CSV в разделе «Источники и права».

Студия: поиск моментов

Как писать запрос

РаботаетХуже
«Моменты, где он уверен в себе, а потом всё идёт не так»«Смешное»
«Реакции на донаты, где он не ожидал сумму»«Донаты»
«Где гость перебивает и выигрывает спор»«Интересные места»
«Все места с фразой «ну это база», склей в один ролик»«Нарезка мемов»

Точная фраза в кавычках «…» ищется по словам без модели — во всех местах, с учётом ё/е и пунктуации.

Флажки

  • Склеить в один ролик — все взятые моменты станут одной компиляцией.
  • Авторежим — моменты с оценкой от 7 берутся и рендерятся сами. Публикация всё равно остаётся за вами.
  • Вырезать паузы внутри клипов — тишина длиннее 0,6 с вырезается по таймкодам слов, на стыках мягкие аудиопереходы 30 мс.

Кандидаты

У каждого — превью, место на шкале видео, цитата-панчлайн, оценки четырёх менторов и риски. «Взять» — в рендер, «В монтаж» — точная правка на таймлайне, «Сохранить время» — поправить границы.

Ручной режим (без Claude Code)

«Настройки → Claude → Вручную через claude.ai». Задача остановится на шаге «Ждёт ответа Claude» — нажмите «Открыть промпт», скопируйте его в чат claude.ai, вставьте JSON-ответ обратно.

Экспорт в монтажку

В панели задачи: EDL для монтажки — таймлайн для DaVinci Resolve и Premiere (File → Import → Timeline; исходники заранее добавьте в Media Pool). CSV для LosslessCut — отрезки для быстрой нарезки без перекодирования.

Монтажный стол

Раздел «Монтаж» — для точной ручной работы: плеер, таймлайн с раскадровкой и волной звука, транскрипт с переходом по словам. Можно резать и без Claude вообще.

  1. Найдите место

    Кликните по слову в транскрипте или по таймлайну. Поиск по тексту — над транскриптом.

  2. Выделите отрезок

    Протяните мышью по таймлайну, нажмите I и O во время просмотра или кликните по времени фразы. Shift+клик по слову ставит конец выделения.

  3. Проверьте

    P проигрывает только выделение. «Кадры выделения» показывают лист кадров.

  4. Оформите и вырежьте

    Название, хук, формат, субтитры, вырезание пауз → «Вырезать клип» или Enter.

Горячие клавиши

КлавишаДействие
ПробелПуск / пауза

Жёлтые области на таймлайне — кандидаты от менторов, зелёные — уже взятые или отрендеренные. Масштаб — ползунок под таймлайном.

Ремесло: советы менторов

Эти правила зашиты в промпт (prompts/mentors.md). Их полезно знать самому, чтобы быстро решать «брать или нет».

Монтажёр

структура и тайминг

  • Одна история: завязка → нарастание → панчлайн → реакция
  • Вход как можно позже, но понятно, что происходит
  • Конец через 0,5–1,5 с после панчлайна, на реакции
  • 15–45 с — лучшая длина; две шутки — два клипа

Комик

что смешно постороннему

  • Ожидание против реальности; уверенность → провал
  • Неожиданный ответ, оговорка, абсурдная эскалация
  • Самоирония; второй участник «переигрывает» героя
  • Не работает: внутренние мемы, смех без причины, травля

Аналитик удержания

досмотрят ли и перешлют ли

  • Первые 1–2 секунды: цепляющая фраза или уже действие
  • Хук до 5 слов, задаёт вопрос, не спойлерит
  • Название конкретное, без пустого кликбейта
  • Плюс: хочется переслать, концовка закольцована

Редактор-юрист

можно ли публиковать

  • Только с основанием из белого списка
  • Нет случайных людей и детей в неловком положении
  • Обрезка не меняет смысл сказанного
  • Мат в панчлайне — запикать или возрастная отметка

Чек-лист перед публикацией

— отметки сохраняются в этом браузере.

Ритм

1–3 сильных клипа в день лучше десяти средних: площадки оценивают удержание каждого ролика. Делайте серии с одним оформлением. Через неделю смотрите статистику: какие хуки и длины держат — те и просите у менторов в запросе.

MCP-сервер: Claude смотрит и режет сам

Clip Studio — ещё и MCP-сервер. Подключите его, и в Claude Code или Claude Desktop появятся инструменты:

ИнструментЧто делает
list_videos, list_sourcesБиблиотека и белый список
transcript, search_transcriptТекст с таймкодами, поиск фразы
lookЛист кадров отрезка — Claude видит, что происходит в кадре
find_moments, candidates, render_jobАвтопоиск менторами и рендер
cutВырезать клип по времени с хуком, субтитрами и вырезанием пауз
clip_previewКадры готового клипа — самопроверка

Подключение: «Настройки → Подключение к Claude → Подключить к Claude Code» (или «к Claude Desktop», затем перезапустите Desktop). Из терминала:

ClipStudio.exe connect-claude --desktop      # готовая программа
python -m clipstudio connect-claude --desktop   # из исходников

Проверка в Claude Code: команда /mcp — в списке должен быть clip-studio. Дальше просто пишите: «Посмотри видео 3, найди, где он роняет телефон, и вырежи вертикальный клип».

Плагин со скиллами

/plugin install clip-studio --marketplace skynet-skynet/clip-studio

Скиллы: /clip-studio:clip — нарезка от поиска до проверки, /clip-studio:watch — посмотреть видео глазами, /clip-studio:mentors — советы и разбор, /clip-studio:publish — публикация. Репозиторий приватный, поэтому на компьютере должен быть вход в GitHub.

Слэш-команды в папке проекта

Если открыть Claude Code в папке исходников, работают /clip, /add-source, /mentor, /setup. Читать файл .env с ключами Claude Code в проекте запрещено настройками.

С телефона

В папке программы выполните claude remote-control и откройте сессию в приложении Claude или на claude.ai/code. Монтаж идёт на вашем компьютере — он должен быть включён.

Облачные кредиты Claude Code

Кредиты облачных сессий тратятся на Claude Code в облаке (claude.ai/code с подключённым репозиторием). Их удобно тратить на доработку самой программы: новые функции, стиль субтитров, тесты. Резать видео в облаке нельзя — у облака нет ваших файлов, а видеоплощадки оттуда закрыты.

Площадки

VK Видео

  1. Создайте сообщество ВКонтакте под нарезки — канал VK Видео создаётся на его основе. Числовой ID (из адреса club123456) впишите в «Настройки → VK Видео».
  2. Создайте приложение в кабинете разработчика VK ID (dev.vk.com), тип — веб. Доверенный адрес перенаправления: http://127.0.0.1:8765/api/auth/vk/callback.
  3. ID приложения сохраните как VK_CLIENT_ID и нажмите «Войти через VK ID». Если доступ к видео не выдаётся, используйте ссылку «старый способ» и вставьте токен вручную.

Приватная загрузка: на свою страницу — «только я»; в сообщество — приватным файлом, который вы публикуете вручную. Шаги VK ID сверьте с документацией VK: при сборке её сайт был недоступен.

YouTube

  1. Google Cloud Console → новый проект → включите YouTube Data API v3.
  2. OAuth consent screen: External, добавьте себя в Test users. Credentials → OAuth client ID → тип Desktop app → скачайте JSON.
  3. Положите файл как secrets/youtube_client_secret.json рядом с программой, включите YouTube и нажмите «Войти в YouTube».

Загрузки идут из отдельной квоты: до 100 видео в сутки. Вертикальные клипы до 3 минут получают #Shorts.

Telegram

  1. @BotFather → /newbot → токен в «Настройки» как TELEGRAM_BOT_TOKEN.
  2. Добавьте бота админом канала с правом публикации, канал укажите как @username.
  3. Для черновиков: напишите боту /start, узнайте свой ID у @userinfobot и впишите в «Чат для черновиков».

Бот отправляет файлы до 50 МБ — минутный клип обычно 15–30 МБ.

Rutube, Дзен, VK Клипы, Одноклассники

Удобного открытого API нет, поэтому программа собирает пакет: видео, обложку и тексты под лимиты каждой площадки, плюс инструкцию. Ручная загрузка занимает около минуты.

Монетизация и закон

Сначала права на доход

Зарабатывать на нарезке чужого видео можно, только если автор это разрешил. Частая схема — деление дохода или плата за клип. Площадки тоже требуют оригинальности: безопаснее всего свои стримы и нарезки с разрешением и заметной обработкой.

Реестр блогеров

С 1 ноября 2024 владельцы страниц с аудиторией больше 10 000 подписчиков подают сведения в Роскомнадзор — по каждой площадке отдельно, в течение 10 дней после порога, через Госуслуги. С 1 января 2025 реклама в незарегистрированных каналах запрещена. Во ВКонтакте, Одноклассниках, Дзене и на Rutube с 8 апреля 2025 отметку можно получить автоматически.

Маркировка рекламы

Каждая интеграция: пометка «Реклама», рекламодатель и идентификатор erid от оператора рекламных данных (ОРД); сведения уходят в ЕРИР. Кто получает erid и отчитывается — закрепите в договоре.

Налоги

Для старта проще всего самозанятость (НПД): 4% с доходов от физлиц, 6% от компаний и ИП, лимит 2,4 млн ₽ в год, регистрация в приложении «Мой налог». Условия проверяйте на npd.nalog.ru. Это ориентир, а не налоговая консультация.
