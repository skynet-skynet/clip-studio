# Clip Studio: полный гайд

Clip Studio — локальная студия нарезок. Вы пишете, какие моменты нужны, а приложение делает остальное: находит видео в разрешённых источниках, распознаёт речь, отбирает моменты руками «редакции менторов» на Claude, монтирует вертикальные клипы с субтитрами и публикует их в VK, YouTube и Telegram. Для Rutube, Дзена, VK Клипов и Одноклассников оно готовит папку для ручной загрузки.

> Подробная иллюстрированная методичка — `docs/manual.html` (в программе — пункт меню «Методичка»). Этот файл — краткая версия.

Актуальность фактов о площадках — октябрь 2026 года. Правила меняются часто, поэтому в каждом разделе есть ссылка на первоисточник. Я не юрист и не налоговый консультант: юридические и налоговые разделы — это ориентир, а не консультация.

## Как это работает

1. **Источник.** Вы добавляете автора или канал в белый список и указываете основание: свои видео, письменное разрешение, CC BY или общественное достояние.
2. **Видео.** Загружаете файл или вставляете ссылку. Юридический шлюз проверяет основание до скачивания и записывает решение в реестр прав.
3. **Транскрипт.** faster-whisper распознаёт речь со временем каждого слова. Если у видео есть субтитры .srt/.vtt, распознавание не нужно.
4. **Поиск моментов.** Claude Sonnet читает транскрипт кусками по 8 минут. Внутри промпта работают четыре ментора: монтажёр, комик, аналитик удержания и редактор-юрист. Каждый ставит свою оценку. Точные фразы в кавычках ищутся без модели.
5. **Выбор и монтаж.** Вы отмечаете, что брать. ffmpeg режет с точностью до кадра, делает 9:16 с размытым фоном, крупные субтитры с подсветкой слов, хук-заголовок, титр с автором и выравнивает громкость до −14 LUFS.
6. **Разбор и публикация.** Claude Opus смотрит готовый клип целиком и выносит вердикт: выпускать, править или не выпускать. Он предлагает названия, хуки и подрезку, которые применяются одной кнопкой. Публикация по умолчанию идёт приватно или черновиком.

### Кто что делает: Opus и Sonnet

| Работа | Модель | Почему |
|---|---|---|
| Поиск моментов в транскрипте | Sonnet | Много текста, нужна скорость и низкая цена |
| Разбор готового клипа менторами | Opus | Одно решение на клип, важна точность суждения |
| Точные фразы в кавычках | без модели | Нечёткий поиск по словам, бесплатно |

Модели переключаются в «Настройках». На Opus можно перевести и поиск: точнее, но дороже.

## Установка

Нужны три вещи: Python 3.10 или новее, ffmpeg и сам проект.

### Windows

1. Установите Python с [python.org](https://www.python.org/downloads/). В установщике отметьте **Add python.exe to PATH**.
2. Установите ffmpeg: откройте PowerShell и выполните `winget install Gyan.FFmpeg`, затем перезапустите PowerShell.
3. Скачайте проект: на странице репозитория на GitHub нажмите **Code → Download ZIP** и распакуйте. Можно и через git: `git clone https://github.com/skynet-skynet/clip-studio`.
4. Дважды щёлкните `start.bat`. Первый запуск создаёт окружение и ставит зависимости, это займёт несколько минут. Потом откроется браузер с адресом `http://127.0.0.1:8765`.

### macOS

1. Поставьте [Homebrew](https://brew.sh), затем выполните `brew install python ffmpeg`.
2. Скачайте проект, откройте Терминал в его папке и выполните `./start.sh`.

### Linux

1. Выполните `sudo apt install python3 python3-venv ffmpeg` (или аналог для вашего дистрибутива).
2. В папке проекта выполните `./start.sh`.

### Видеокарта

Распознавание речи работает и на процессоре. Модель `small` обрабатывает час видео примерно за 15–40 минут, в зависимости от процессора. С видеокартой NVIDIA ставьте модель `large-v3` и устройство `cuda`: это быстрее и точнее. Подробности в документации [faster-whisper](https://github.com/SYSTRAN/faster-whisper).

### Что ставится дополнительно

- YouTube: `pip install google-api-python-client google-auth-oauthlib`
- Режим Anthropic API: `pip install anthropic`
- Кадрирование по лицу: `pip install opencv-python-headless`

Всё сразу ставится одной командой: `pip install -r requirements-extra.txt`.

## Claude Code: три способа связать

### 1. Через подписку (по умолчанию)

Режим `claude_cli`. Приложение само вызывает установленный Claude Code в фоновом режиме. Тратятся лимиты вашей подписки Pro или Max, отдельный ключ не нужен.

Установка Claude Code ([официальная инструкция](https://code.claude.com/docs/en/setup)):

- Windows, PowerShell: `irm https://claude.ai/install.ps1 | iex`
- macOS и Linux: `curl -fsSL https://claude.ai/install.sh | bash`

После установки один раз запустите `claude` в терминале и войдите через браузер. Бесплатный план claude.ai Claude Code не включает: нужен Pro, Max, Team, Enterprise или аккаунт Console.

### 2. Слэш-команды в папке проекта

Откройте терминал в папке Clip Studio и запустите `claude`. В проекте уже лежат инструкции (`CLAUDE.md`) и команды:

- `/clip 5 клипов, где он спорит с чатом` — весь путь от поиска до готовых клипов
- `/add-source` — добавить автора в белый список с проверкой основания
- `/mentor 7` — разбор клипа менторами
- `/setup` — проверить и донастроить установку

Claude Code в проекте не может читать `.env` с ключами: это запрещено в `.claude/settings.json`.

### 3. Управление с телефона или из браузера (Remote Control)

В папке проекта выполните `claude remote-control`. Claude Code покажет ссылку и QR-код. Откройте сессию на [claude.ai/code](https://claude.ai/code) или в приложении Claude на телефоне. Писать `/clip …` можно с дивана, а монтаж идёт на вашем компьютере. Компьютер и терминал должны оставаться включены. Функция доступна на планах Pro, Max, Team и Enterprise ([документация](https://code.claude.com/docs/en/remote-control)).

### Ручной режим (без Claude Code)

Режим `manual`. Приложение показывает готовый промпт. Вы вставляете его в чат на claude.ai, копируете JSON-ответ обратно и нажимаете «Отправить ответ». Это медленнее, но работает на любом устройстве.

### Режим Anthropic API

Режим `api`. Нужен ключ из [Claude Console](https://platform.claude.com) в `.env` (`ANTHROPIC_API_KEY`), оплата по токенам. Удобен, если нарезка идёт на сервере без входа в подписку.

### Облачные сессии Claude Code

Облачные кредиты (Cloud session credits в настройках claude.ai) тратятся на сессии Claude Code в облаке, например на [claude.ai/code](https://claude.ai/code) с подключённым репозиторием. Для Clip Studio они полезны, чтобы дорабатывать само приложение: добавить площадку, поменять стиль субтитров, прогнать тесты. Нарезать видео в облаке не получится: у облачной сессии нет доступа к вашим файлам, а сайты видеоплощадок закрыты. Монтаж всегда идёт на вашем компьютере.

## Права: что можно резать

Главное правило Clip Studio: **режем только то, на что есть основание**. Приложение не даёт обойти это правило: видео из источника не из белого списка не скачивается.

### Основания

| Основание | Когда | Что хранить |
|---|---|---|
| `own` | Видео ваше | Ничего |
| `permission` | Автор письменно разрешил нарезки | Скриншот переписки или ссылку на правила канала, дату и условия |
| `cc-by` | Конкретное видео опубликовано под Creative Commons Attribution | Ссылку на оригинал. Автор указывается в каждом клипе |
| `public-domain` | Срок охраны истёк или автор отказался от прав | Источник, подтверждающий статус |

Лицензия CC BY-ND (без производных) нарезку не разрешает: монтаж, субтитры и обрезка делают производное произведение. Шлюз отклоняет такие видео.

### Почему не «цитирование»

Статья 1274 ГК РФ разрешает цитировать в информационных, научных, критических и учебных целях в объёме, оправданном целью. Канал из подряд идущих смешных фрагментов чужого видео под эту цель обычно не подходит. В нём нет разбора, критики или новости. Поэтому Clip Studio на цитирование не опирается.

### Люди в кадре

Статья 152.1 ГК РФ охраняет изображение гражданина. Ментор-юрист снижает оценку моментам, где высмеивают случайных людей (прохожих, сотрудников, детей), и помечает такие места. Если сомневаетесь, не публикуйте или заблюрьте лицо.

### Как получить разрешение автора

Многие стримеры и блогеры рады клипмейкерам: нарезки приводят им новую аудиторию. Короткое письмо работает лучше длинного:

> Привет! Я делаю нарезки смешных моментов (пример: ссылка). Хочу резать ваши стримы для VK Клипов и Shorts. В каждом клипе будет ваш ник и ссылка на канал. Можно ли? Есть ли темы, которые не трогать? Можно ли включать монетизацию на нарезках, или делим доход?

Ответ сохраните скриншотом в папку `proofs/` и укажите путь в поле «Доказательство».

### Реестр прав

Каждое решение шлюза (разрешено или заблокировано, почему, по какому доказательству) пишется в реестр. Его можно выгрузить в CSV в разделе «Источники и права». Если правообладатель пришлёт жалобу, у вас будет ответ за минуту.

## Площадки: регистрация и подключение

### VK Видео

**Регистрация.** Удобнее публиковать от имени сообщества, а не личной страницы. Создайте сообщество ВКонтакте под нарезки. Канал в VK Видео создаётся на его основе. Узнайте числовой ID сообщества (в адресе `club123456` это `123456`) и впишите его в «Настройки → VK Видео → ID сообщества».

**Ключ доступа.** Для загрузки через API нужен ключ пользователя с правом `video`. Вы должны быть администратором сообщества.

1. Создайте приложение в кабинете разработчика VK ID (вход через [dev.vk.com](https://dev.vk.com), раздел «VK ID»). Тип — веб-приложение.
2. В настройках приложения добавьте доверенный адрес перенаправления: `http://127.0.0.1:8765/api/auth/vk/callback`.
3. Скопируйте ID приложения и сохраните его в «Настройках» как `VK_CLIENT_ID`.
4. Нажмите «Войти через VK ID». Токен сохранится сам.

Если VK ID не выдаёт доступ к видео (права для новых приложений иногда выдаются после модерации), под кнопкой появится ссылка на старый способ. После входа токен виден в адресной строке после `access_token=`. Скопируйте его в поле «Токен VK».

Документацию VK при сборке проверить не удалось (сайт dev.vk.com был недоступен из среды сборки), поэтому шаги по VK ID сверьте с документацией на [dev.vk.com](https://dev.vk.com). Загрузка идёт методом `video.save` с последующей отправкой файла на выданный адрес. Если VK сменит адреса авторизации, их можно поменять в `config.yaml` (`publish.platforms.vk.id_base`).

**Приватность.** На личную страницу видео загружается с видимостью «только я». В сообщество оно загружается приватным и не появляется в списке видео, пока вы не опубликуете его вручную.

### YouTube

Важно для авторов из России: регистрация в партнёрской программе YouTube (монетизация) для них сейчас недоступна, см. раздел «Монетизация». Загружать видео при этом можно.

1. Откройте [Google Cloud Console](https://console.cloud.google.com) и создайте проект.
2. В разделе **APIs & Services → Library** включите **YouTube Data API v3**.
3. В разделе **OAuth consent screen** выберите тип External, заполните название и почту, добавьте себя в **Test users**.
4. В разделе **Credentials → Create credentials → OAuth client ID** выберите тип **Desktop app**. Скачайте JSON.
5. Положите файл в папку проекта как `secrets/youtube_client_secret.json`.
6. Включите YouTube в «Настройках» и нажмите «Войти в YouTube». В открывшемся браузере выберите аккаунт с каналом.
7. Для поиска видео под CC BY создайте там же **API key** и сохраните его как `YOUTUBE_API_KEY`.

**Квоты.** По [официальной документации](https://developers.google.com/youtube/v3/docs/videos/insert) загрузка `videos.insert` теперь идёт из отдельной квоты: 1 единица за вызов, до 100 загрузок в сутки. Вертикальные клипы до 3 минут автоматически получают тег #Shorts.

### Telegram

1. Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`, придумайте имя и получите токен. Сохраните его как `TELEGRAM_BOT_TOKEN`.
2. Создайте канал и добавьте бота администратором с правом публиковать сообщения.
3. В «Настройках → Telegram» укажите канал в виде `@username`.
4. Для черновиков напишите своему боту `/start`, узнайте свой числовой ID у [@userinfobot](https://t.me/userinfobot) и впишите его в «Чат для черновиков». Приватные публикации будут приходить вам, а не в канал.

Бот загружает файлы до 50 МБ. Клип на 60 секунд обычно весит 15–30 МБ.

### Rutube, Дзен, VK Клипы, Одноклассники

У этих площадок нет удобного открытого API для загрузки, поэтому приложение готовит **пакет для ручной загрузки**. Это папка с видео, обложкой, названием и описанием под лимиты каждой площадки, плюс пошаговая инструкция. Загрузка вручную занимает около минуты на площадку.

- **Rutube:** зарегистрируйтесь и загружайте через [Rutube Studio](https://studio.rutube.ru).
- **Дзен:** вертикальные ролики загружаются через редактор Дзена.
- **VK Клипы:** через мобильное приложение ВКонтакте, раздел «Клипы», от имени сообщества.
- **Одноклассники:** через группу, раздел «Видео».

## Монтажный стол и Claude как MCP

- **Монтаж** — плеер, таймлайн с раскадровкой и волной звука, транскрипт с переходом по словам. Выделите отрезок мышью или клавишами `I` / `O`, нажмите «Вырезать клип» (`Enter`). Флажок «Вырезать паузы» убирает тишину длиннее 0,6 с.
- **Экспорт** — в панели задачи: EDL для DaVinci Resolve и Premiere, CSV для LosslessCut.
- **MCP-сервер** — «Настройки → Подключение к Claude». После этого Claude Code и Claude Desktop умеют смотреть кадры видео (`look`), читать транскрипт, резать (`cut`) и проверять готовый клип (`clip_preview`).
- **Плагин для Claude Code** — `/plugin install clip-studio --marketplace skynet-skynet/clip-studio`, скиллы `/clip-studio:clip`, `:watch`, `:mentors`, `:publish`.
- **Готовая программа для Windows** — архив `ClipStudio-windows.zip` в Releases репозитория (ffmpeg внутри).

## Как пользоваться

1. **Источники и права.** Добавьте себя (`own`) и авторов с разрешением.
2. **Видео.** Загрузите файл или вставьте ссылку. Субтитры (.srt/.vtt) ускоряют работу: распознавание не понадобится.
3. **Студия.** Напишите запрос, выберите видео и нажмите «Найти моменты».
4. Просмотрите кандидатов: у каждого есть превью, оценки менторов, цитата и риски. Поправьте время, если нужно. Нажмите «Взять» на нужных, затем «Отрендерить».
5. **Клипы.** Откройте клип и нажмите «Разбор менторами». Выберите название и хук, при необходимости отметьте подрезку и нажмите «Применить правки».
6. Отметьте площадки и нажмите «Опубликовать». Проверьте черновик на площадке и опубликуйте его там.

### Как писать запрос

- Про что: «моменты, где он спорит с чатом», «фейлы в готовке», «реакции на донаты».
- Про кого: «только где говорит гость».
- Точная фраза в кавычках: «ну это база». Её найдут без модели, во всех местах.
- Формат: «склей в один ролик на минуту», «горизонтально для VK Видео».

**Авторежим** сам берёт моменты с оценкой от 7 и рендерит их. Публикация всё равно остаётся за вами.

## Как делать нарезки: советы менторов

Эти правила зашиты в промпт менторов (`prompts/mentors.md`). Их полезно знать и самому, чтобы быстро принимать решения.

### Монтажёр: структура

- Клип — одна законченная история: завязка, нарастание, панчлайн, реакция.
- Входите в момент как можно позже, но так, чтобы было понятно, что происходит. Приветствия, «короче» и раскачку режьте.
- Заканчивайте через полсекунды–полторы после панчлайна, на реакции. Не обрывайте на полуслове.
- 15–45 секунд — лучшая длина для Клипов и Shorts. До 60 — если есть нарастание.
- Две разные шутки — два клипа, а не один.

### Комик: что смешно постороннему

- Ожидание против реальности: «сейчас всё сделаю», а потом провал.
- Неожиданный ответ, оговорка, абсурдная эскалация.
- Честная самоирония после фейла.
- Второй участник (чат, гость, кот) «переигрывает» главного героя.
- Не работает: внутренние мемы канала без расшифровки, смех без видимой причины, издевательство над кем-то конкретным.

### Аналитик удержания: досмотрят ли

- Первые 1–2 секунды решают всё. Первая фраза должна цеплять, или действие уже должно идти.
- Хук на экране — до 5 слов. Он задаёт вопрос и не раскрывает панчлайн. «ПЛАН БЫЛ ИДЕАЛЬНЫЙ» работает, «ОН УРОНИЛ ШКАФ» — спойлер.
- Название конкретное, без кликбейта, который клип не оправдывает.
- Хорошо работают клипы, которые хочется переслать («скинь тому, кто не читает инструкции») и концовки, закольцованные на начало.

### Редактор-юрист: можно ли публиковать

- Нет случайных людей в унизительном положении, детей в неловких ситуациях, оскорблений по признаку национальности, религии и тому подобного.
- Обрезка не меняет смысл сказанного.
- Мат в панчлайне запикивайте или ставьте возрастную отметку.
- Правила автора из белого списка соблюдаются всегда.

### Ритм публикаций

- Лучше 1–3 сильных клипа в день, чем 10 средних: площадки оценивают удержание каждого ролика.
- Делайте серии с узнаваемым оформлением (один шрифт, один цвет хука). Clip Studio делает это автоматически.
- Смотрите статистику через неделю. Какие хуки и длины удерживают лучше — те и просите у менторов в запросе.

## Монетизация

### Сначала — права на доход

Зарабатывать на нарезке чужого видео можно, только если автор это разрешил. В белом списке для этого есть галочка «Автор разрешил монетизацию». Без неё клип помечается красным, а в пакете для ручной загрузки появляется предупреждение. Частая схема с авторами — деление дохода или фиксированная плата за клип.

Площадки тоже требуют оригинальности. Например, в новой программе VK Видео условие — оригинальный контент. Нарезки собственных стримов и нарезки с разрешением и заметной обработкой (монтаж, субтитры, хуки) — самый безопасный путь.

### Условия площадок (октябрь 2026)

| Площадка | Монетизация | Что известно |
|---|---|---|
| VK Видео | Есть | С 1 сентября 2026 порог снижен: от 1 000 подписчиков и 500 часов просмотра за 90 дней, контент должен быть оригинальным. Для тех, кому не хватает часов, есть адаптационный период с гарантированным минимумом. Авторам уходит 50–80% рекламной выручки |
| Rutube | Есть | Выплаты за рекламу в роликах, в среднем порядка 50–150 ₽ за 1 000 просмотров с рекламой. Во втором полугодии 2026 Rutube готовит монетизацию вертикальных Shorts |
| Дзен | Только тексты | С 14 апреля 2025 рекламная монетизация в Дзене работает для статей и постов. Видео зарабатывают через Дзен Премиум и донаты |
| YouTube | Недоступна для России | Новые подключения к партнёрской программе для авторов из России закрыты с марта 2022 |
| Telegram | Нестабильно | Встроенная доля от Telegram Ads для каналов от 1 000 подписчиков появлялась у российских каналов в 2024, затем СМИ сообщали об её отключении. Проверьте в статистике своего канала. Надёжнее прямые рекламные интеграции |

Пороги и проценты меняются: перед подключением сверяйтесь с кабинетом автора на площадке.

### Другие способы заработка

- **Клипмейкинг на заказ.** Стримерам и подкастерам нужны нарезки. Clip Studio позволяет делать их быстро: предложите автору пакет «N клипов в неделю» за фикс или процент.
- **Реклама в своих каналах.** С ростом аудитории приходят интеграции. Их нужно маркировать (см. ниже).
- **Донаты и платный контент.** VK, Rutube, Дзен и Telegram (Stars, платные посты) поддерживают поддержку от зрителей.

### Реестр блогеров (10 000+ подписчиков)

С 1 ноября 2024 владельцы страниц с аудиторией больше 10 000 подписчиков обязаны подать сведения в Роскомнадзор. Порог считается **по каждой площадке отдельно**, сведения подаются в течение 10 дней после достижения порога через Госуслуги. С 1 января 2025 размещать рекламу в незарегистрированных каналах запрещено. Во ВКонтакте, Одноклассниках, Дзене и на Rutube с 8 апреля 2025 отметку о регистрации можно получить автоматически.

### Маркировка рекламы

Любую рекламную интеграцию нужно маркировать. Пометка «Реклама», указание рекламодателя и идентификатор erid, который выдаёт оператор рекламных данных (ОРД). Сведения о размещении передаются в ЕРИР. Кто именно получает erid и отчитывается, закрепите в договоре с рекламодателем.

### Налоги

Доход от площадок и рекламы — это доход, с которого платится налог. Самый простой вариант для старта — самозанятость (налог на профессиональный доход): 4% с доходов от физлиц и 6% от компаний и ИП, лимит 2,4 млн ₽ в год. Регистрация — в приложении «Мой налог». Условия проверяйте на [npd.nalog.ru](https://npd.nalog.ru) перед подключением. Если доход растёт выше лимита — переходите на ИП.

## Стоимость Claude

- **Режим подписки** (`claude_cli`): платите только за подписку, нарезка расходует её лимиты.
- **Режим API:** в тестовом прогоне поиск моментов в 2-минутном транскрипте на Sonnet стоил около $0,03. Час стрима — порядка нескольких десятков центов на Sonnet. Разбор одного клипа на Opus стоит дороже поиска, поэтому разбирайте только те клипы, которые собираетесь публиковать.
- **Ручной режим:** ничего сверх подписки claude.ai.

Стоимость каждой задачи видна в списке задач (≈ $). Экономия: давайте субтитры вместо распознавания, уменьшайте `chunk_minutes` только если модель пропускает моменты.

## Если что-то не работает

| Проблема | Что делать |
|---|---|
| «ffmpeg не найден» | Установите ffmpeg (раздел «Установка») и перезапустите приложение |
| «Claude Code не найден» | Установите Claude Code и войдите командой `claude`, или включите ручной режим |
| Распознавание очень медленное | Модель `small` или `base`, загружайте видео с субтитрами, или используйте видеокарту |
| VK: код 5 | Токен истёк — войдите заново через «Настройки» |
| VK: код 15 или 7 | Нет прав: проверьте, что вы админ сообщества и токен выдан с правом video |
| YouTube: лимит исчерпан | Суточная квота загрузок закончилась — попробуйте завтра |
| Telegram: файл больше 50 МБ | Сделайте клип короче или увеличьте `crf` в настройках клипов |
| Субтитры не тем шрифтом | Шрифт лежит в папке `fonts/`, не удаляйте её |

## Где что лежит

- `data/videos` — исходники; `data/transcripts` — транскрипты; `data/clips` — готовые клипы; `data/packs` — пакеты для ручной загрузки
- `data/clipstudio.db` — база: задачи, кандидаты, клипы, публикации, реестр прав
- `sources.yaml` — белый список; `config.yaml` — настройки; `.env` — ключи (никому не отправляйте)
- `proofs/` — доказательства разрешений
- `prompts/` — промпты менторов, их можно править под свой стиль

Для резервной копии сохраняйте `sources.yaml`, `proofs/` и `data/clipstudio.db`.
