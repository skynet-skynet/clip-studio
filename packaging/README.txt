Clip Studio — нарезка смешных моментов из видео
==============================================

Запуск
  1. Распакуйте папку в «Документы» (не в Program Files).
  2. Запустите ClipStudio.exe. Откроется окно программы.
     Чёрное окно консоли не закрывайте, пока работаете: это сервер программы.
  3. Если Windows SmartScreen предупредит: «Подробнее» → «Выполнить в любом случае».

Что нужно отдельно
  - Claude Code с подпиской Pro или Max — для автоматического поиска моментов.
    Установка (PowerShell):  irm https://claude.ai/install.ps1 | iex
    затем один раз выполните  claude  и войдите.
    Без Claude Code работает ручной режим через claude.ai (Настройки → Claude).
  - Интернет при первой транскрибации: скачивается модель распознавания речи.

Подключить к Claude Code / Claude Desktop как MCP-сервер
  В программе: Настройки → «Подключение к Claude».
  Или в терминале:  ClipStudio.exe connect-claude --desktop

Методичка
  Metodichka-ClipStudio.html в этой папке, а также пункт «Методичка» в меню программы.

Где ваши данные
  data\      — видео, транскрипты, клипы, база
  .env       — ключи площадок (никому не отправляйте)
  sources.yaml, config.yaml — белый список и настройки

ffmpeg внутри сборки — сборка BtbN (GPL), лицензия в _internal\ffmpeg\LICENSE.txt.
