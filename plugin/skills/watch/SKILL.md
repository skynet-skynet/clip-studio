# Просмотр видео через кадры

Claude не смотрит видео потоком. Он смотрит листы кадров (`look`) и читает транскрипт (`transcript`).

1. `list_videos` → нужное видео и его длительность.
2. Обзор: несколько вызовов `look` по крупным отрезкам (например, по 5 минут, `frames=9`), чтобы понять, где действие.
3. Подозрительные места — крупнее: `look` на 10–20 секунд с `frames=12`.
4. Сверяй с речью: `transcript(video_id, start, end)` для того же отрезка.
5. Визуальные признаки сильного момента: резкая смена позы, падение, предмет ломается, неожиданный объект в кадре,
   лицо в крупном плане с яркой эмоцией, второй человек входит в кадр.
6. Опиши находки с таймкодами в секундах, чтобы их можно было сразу вырезать через `cut`.

Кадры на листе идут слева направо, сверху вниз; времена кадров приходят в подписи к картинке.
