# Нарезка клипов через Clip Studio

Нужны инструменты MCP-сервера `clip-studio` (`mcp__clip-studio__*`). Если их нет, скажи пользователю:
открыть Clip Studio → «Настройки» → «Подключить к Claude Code» (или выполнить `python -m clipstudio connect-claude`)
и перезапустить Claude Code.

## Правила, которые не нарушаются
- Видео берётся только из белого списка источников (`list_sources`). Нет основания — не ищи обходных путей,
  предложи пользователю попросить разрешение у автора.
- Публикация — только `privacy="private"`, если пользователь прямо не попросил публично.
- Если у источника `monetization_allowed: false`, не советуй монетизировать клип.

## Порядок работы
1. `list_videos` — выбери видео под запрос. Если подходящего нет — `list_sources` и предложи `import_file` / `import_url`.
2. Найди моменты одним из способов:
   - сам: `transcript` (кусками по `start`/`end`) и `search_transcript` для точных фраз;
   - автоматически: `find_moments` (редакция менторов на Sonnet) → `candidates`.
3. Для 1–3 лучших моментов вызови `look` на отрезке: проверь, что визуально всё в порядке
   (нет посторонних людей в неловком положении, кадр не пустой, реакция видна).
4. Режь: `cut(video_id, start, end, title, hook, format="vertical", jumpcut=...)`.
   - начало — с первой фразы завязки, конец — через 0,5–1,5 с после панчлайна, на реакции;
   - хук — до 5 слов, без спойлера панчлайна;
   - `jumpcut=true`, если внутри много пауз.
5. Проверь результат: `clip_preview`. Если хук закрывает лицо или субтитры не совпадают — поправь и перережь.
6. По желанию: `review` (вердикт менторов на Opus), затем `publish(..., privacy="private")`.
7. Ответь пользователю коротко: какие клипы готовы (номер, длина, название), что проверил глазами.
